# Rules

## Releases

- `main` branch
  - stable version (behavior confirmed)
- `devlop` branch
  - beta version (may contain bugs)

## Regular brunch

- `feature/**` branches
  - Add new features
- `hotfix/**`
  - Fix for conventional function
- `evaluation/**`
  - Performance evaluation of functions
- `chore/**`
  - Content not related to core functionality
  - ex. ) Document creation, Repository maintenance, ...
